# Bang & Olufsen Landing Page

A responsive Bang & Olufsen landing page built from a Figma design. The project features adaptive layouts, a burger menu with scroll locking, interactive phone contact link, product sections, contact form, hover effects, and smooth scroll animations.

## Technologies

- HTML5
- JS
- SCSS
- BEM
- Flexbox and CSS Grid
- Vite
- Figma
